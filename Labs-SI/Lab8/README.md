# Lab8. Программный фильтр-сглаживатель

## Задание

```
Программный фильтр в Linux называется передача потока stderr
(вывод программы в консоль) на stdin другой программы.
Программа gen генерирует поток данных, состоящий из
суперпозиции двух гармонических функций, на который наложен
"шум"б состоящий из случайных значений.
Программа osc представляет "осциллоскоп", выводящий график
поступающих сигналов. Каждое четное значение выводится
другим (синим) цветом.
Фильтр 
./gen | ./osc 
запустит показ сгенерированного сигнала.
Задача:
Написать программу-"сглаживатель"-фильтр, уменьшающий шум
сигнала. stdin - входной поток, stdout - сглаженные данные. 
Встроить в цепочку 
./gen | ./filter | ./osc
Сглаживание осуществляется сверткой входного сигнала с
набором коэффициентов сглаживания (в файле PASCAL.txt есть
такие наборы).
Для работы osc нужна библиотека FLTK и класс рисования
графиков функций Cartesian. FLTK есть на каждом компьютере в классе,
Cartesian присутствует в папке с заданием.

 
```

## Сборка и запуск

```bash
./mk.sh            # собрать gen, filter, osc и запустить ./gen | ./filter | ./osc
./mk.sh 6          # то же с набором коэффициентов 6 (Савицкий-Голей, 9 точек)

# без графики (osc требует FLTK):
gcc -Wall -Wextra -std=c99 filter.c -o filter
gcc gen.c -lm -o gen
./gen | ./filter 3 | head
```

## Решение

- `filter` читает числа из stdin и пишет сглаженные значения в stdout (после каждого значения `fflush`, чтобы данные сразу шли по конвейеру).
- Сглаживание - свёртка с набором коэффициентов, делённая на их сумму. Значения хранятся в кольцевом буфере, поэтому поток может быть бесконечным.
- Таблица из 9 наборов из PASCAL.txt: треугольник Паскаля на 3/5/7/9 точек и коэффициенты Савицкого-Голея. Набор выбирается параметром: `./filter номер [проходы]`.
- Служебные сообщения выводятся в stderr, чтобы не мешать данным.
- `gen.c`, `osc.cpp`, `Cartesian.*`, `PASCAL.txt` - файлы из задания.
