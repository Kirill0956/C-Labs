# Lab6. Выпуклая оболочка (QuickHull)

## Задание

```
  Лабораторная работа #6. Выпуклая оболочка на плоскости.

Используя алгоритм QuickHull с предварительной сортировкой по координате X
построить выпуклую оболочку для множества точек, координаты которых 
находятся в файле (для примера дан файл IN.txt). В каждой строке файла
задано целое число (номер точки) и вещественные координаты x и y.
Дополнительные указания:
(1) Использовать библиотечную функцию qsort для сортировки;
(2) Написать вспомогательные функции для проверки, 
    находится ли следующая точка справа или слева
    от луча, соединяющего предпоследнюю точку с последней;
(3) Вывод результат (массив с номерами точек) в файл.

(4) Все исходные точки из файла разместить в массиве
    структур типа POINT.

typedef struct point {
 double x;
 double y;
 int num;  // номер точки в массиве
} POINT *points;
```

## Сборка и запуск

```bash
gcc -Wall -Wextra -std=c99 main.c -o hull
./hull IN.txt              # номера точек оболочки - в OUT.txt
./hull IN.txt res.txt
```

## Решение

- Точки читаются в динамический массив структур `POINT` (x, y, num).
- Предварительная сортировка по X - `qsort`; крайние левая и правая точки - начало и конец оболочки.
- Вспомогательные функции `is_left`/`is_right` через векторное произведение определяют, с какой стороны луча лежит точка.
- QuickHull рекурсивно ищет самую удалённую от отрезка точку и отбрасывает точки внутри треугольника.
- В файл выводится массив номеров точек оболочки (обход по часовой стрелке от самой левой точки).
- Результат для IN.txt проверен независимым алгоритмом (55 точек).
