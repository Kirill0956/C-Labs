# Lab11. Просмотр молекул (GTK + cairo + libmat)

## Задание

```
В каталоге задания: заготовка C.c (окно GTK, рисование cairo, загрузка молекулы, матрицы поворота из libmat), каталог molecules с описаниями молекул и cub.txt (кубик в том же формате).
Нужно дописать программу: нарисовать атомы и связи, реализовать вращение, масштаб, изменение радиуса атомов (r/R) и перспективы (d/D).
```

## Сборка и запуск

```bash
# нужен пакет libgtk-3-dev (Ubuntu: sudo apt install libgtk-3-dev)
make            # или ./C.sh
LD_LIBRARY_PATH=. ./C molecules/benzimid
```

## Решение

- Формат файла: `Nat Nl`, затем Nat строк `номер имя x y z заряд`, затем Nl строк `номер от до тип`.
- Координаты переносятся в центр масс; каждый кадр вершины умножаются на матрицу Rx*Ry*Rz*P (libmat: `mat_fill_x/y/z`, `mat_fill_p`) и делятся на однородную координату.
- Атомы рисуются шарами с радиальным градиентом (цвет по элементу: H, C, N, O, S, P, F, Cl, Br, Zn...), связи - линиями двух цветов. Объекты сортируются по глубине (алгоритм художника), ближние закрывают дальние.
- Исправлена ошибка заготовки: в обработчике `draw` каждый раз создавался новый таймер `g_timeout_add` - теперь один таймер на 30 мс.
- Управление: стрелки, `a/A`, `s/S`, `z/Z` - вращение; пробел - стоп; `0` - исходное положение; `+`/`-` - масштаб; `r/R` - радиус атомов; `d/D` - перспектива; `l` - подписи; `h` - водороды; `q` - выход.
- Расчёт и рисование вынесены в `molecule.c`, интерфейс GTK - в `C.c`.
