# Lab10. Библиотека матриц и тессеракт

## Задание

```
В каталоге задания: библиотека для работы с матрицами (matcreat, matadd, matsub, matmul, mattran, matdump, materr), скрипты makelib/maketest и файл Tesseract.
Нужно собрать библиотеку (динамическую и статическую), проверить её и с её помощью построить изображение тессеракта (четырёхмерного куба).
```

## Сборка и запуск

```bash
make            # собрать libmat.so, libmat.a, test и tesseract
LD_LIBRARY_PATH=. ./test
make run        # или LD_LIBRARY_PATH=. ./tesseract

# вручную:
./makelib.sh
gcc -Wall -std=c99 tesseract.c -L. -lmat -lX11 -lm -o tesseract
```

## Решение

- Библиотека переписана в стиле ANSI C и разбита на модули: `matcreat.c` (создание/удаление), `matfill.c` (матрицы преобразований), `matdump.c` (вывод), `matarith.c` (+, -, *, транспонирование, определитель, обратная матрица).
- Исправлена ошибка `mat_fill_T` из исходной библиотеки (выход за границы вектора переноса).
- `mat_fill_R(A, c1, c2, угол)` - поворот в плоскости координат c1-c2 для пространства любой размерности.
- `tesseract.c`: 16 вершин (±1, ±1, ±1, ±1) и 32 ребра; повороты в 6 плоскостях 4D (XY, XZ, XW, YZ, YW, ZW) матрицами 5x5, перспективная проекция 4D -> 3D, затем поворот и проекция 3D -> 2D матрицами 4x4. Рисование через Xlib с двойной буферизацией.
- Управление: `1`-`6` - вращение в плоскостях, стрелки - камера, `+`/`-` - масштаб, пробел - пауза, `r` - сброс, `q` - выход.
