# Lab4. Транслитерация (ГОСТ 7.79-2000, система Б)

## Задание

```
Задача - написать 2 приложения, преводящий текст на русском языке
в транслит и обратно.

Программа должна считывать много (до 1000) текстовых файлов, разбивая
текст на слова, и для каждого слова подсчитывать количество симолов
в нем. Выровнять текст по правой границе столбца.
Файлы содержат текст на русском языке в кодировке cp1251 (Win1251) и
находятся в каталогах History и Detect.
Вход программы - список файлов, которые необходимо обработать, 
передается через параметры командной строки.
Выход программы - ФАЙЛЫ, переведенные на транслит.

Алгоритм должен быть однопроходным, без повторного считывания
информации из файлов.
```

## Сборка и запуск

```bash
gcc -Wall -Wextra -std=c99 cyr2lat.c align.c -o cyr2lat
gcc -Wall -Wextra -std=c99 lat2cyr.c align.c -o lat2cyr
./cyr2lat History/*.TXT          # создаются файлы *.TXT.lat
./lat2cyr History/*.TXT.lat      # обратно: *.TXT.cyr (cp1251)
./cyr2lat -w 60 файлы...         # ширина столбца 60 (по умолчанию 72)
iconv -f cp1251 -t utf-8 History/LICAR.TXT.cyr   # посмотреть результат
```

## Решение

- Два приложения: `cyr2lat` (русский -> транслит) и `lat2cyr` (обратно), общий модуль `align.c`.
- Таблица ГОСТ 7.79-2000 (система Б): ж-zh, ц-cz (c перед i, e, y, j), ч-ch, ш-sh, щ-shh, ъ-``, ы-y`, ь-`, э-e`, ю-yu, я-ya, ё-yo, х-x, й-j. Учитывается регистр (Zh / ZH).
- Вход - до 1000 файлов в cp1251 через параметры командной строки, каждый читается один раз.
- Строка разбивается на слова, для каждого слова считается число символов; текст выравнивается по правой границе столбца. По каждому файлу выводится статистика слов.
- Проверено: русский текст -> транслит -> русский текст совпадает с исходным по словам.
