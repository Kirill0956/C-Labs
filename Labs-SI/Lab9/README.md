# Lab9. Графика X11

## Задание

```
 X11 - основное средство для вывода графики в UNIX-подобных системах.
```

## Сборка и запуск

```bash
gcc -Wall -Wextra -std=c99 main.c -o draw -lX11
./draw
```

## Решение

Программа-рисовалка на основе примера `X.c` из задания:
- левая кнопка мыши - вершина ломаной (новая фигура получает следующий цвет палитры);
- правая кнопка - замкнуть фигуру;
- `f` - заливка замкнутых фигур, `u` - отменить последнюю фигуру, `c` - очистить, `q` - выход.

Что исправлено по сравнению с примером: все фигуры хранятся в памяти, и при событии `Expose` (окно перекрыли, свернули, изменили размер) рисунок восстанавливается, а не стирается; корректно обрабатывается закрытие окна крестиком (`WM_DELETE_WINDOW`); вся память и ресурсы X11 освобождаются.
